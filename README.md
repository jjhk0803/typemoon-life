# 타입문 인생게임

80억 명 중 하나로 무작위로 태어나, TYPE-MOON 세계관 속에서 한 번의 인생을 사는 웹 게임이에요.

**플레이:** https://jjhk0803.github.io/typemoon-life/

- 나라는 실제 인구 비율대로, 수명은 나라별 기대수명을 바탕으로 정해져요.
- 대부분은 달빛 세계를 모른 채 평범하게 살다 가요. 아주 드물게 마술사 가문에 태어나거나, 사도를 마주치거나, 후유키에서 영주가 새겨져요.
- 성배전쟁에 휘말리면 서번트를 소환해 싸워요.
- 인생이 끝나면 그 삶이 몇분의 1이었는지와 결말 칭호를 알려 줘요. 인생 코드로 같은 인생을 다시 볼 수 있어요.
- `운명 가속 ×100`을 끄면 현실 확률 그대로 진행돼요.

### 시작 방식 세 가지
- **80억분의 1**: 나라도 가문도 무작위. 실제 인구 비율대로 태어나요.
- **마술사 되기 (CYOA)**: 마나·운명력·자본·각인 포인트로 기원, 종족, 출생, 마술속성, 마술계통(시계탑 12학과와 외전), 능력, 마안, 마술예장, 피드백을 고르고, 인생에서 겪을 행적(제4·5차 성배전쟁, 오가와 맨션, 마안수집열차, 알비온 대탐험 등 21가지)을 미리 정해요. 억지력과 계위에 따라 트루, 노멀, ??? 결말이 열려요.
- **운명의 주사위**: 포인트 설계를 무작위로 채워 바로 태어나요.

행적이 오면 선택지를 골라 이야기를 진행해요. 추천 계위보다 약하면 목숨을 잃을 수도 있어요.

설치 없이 브라우저에서 `index.html` 한 파일로 돌아가요.

## 안내

TYPE-MOON의 작품(Fate, 월희, 공의 경계 등) 세계관을 바탕으로 만든 **비공식 비상업 팬 게임**이에요. TYPE-MOON 및 관련 회사와 관계가 없어요. 서번트로 등장하는 인물은 신화·역사 속 인물이고, 게임 속 문장과 수치는 놀이용으로 새로 쓴 것이에요. 「마술사 되기」의 포인트 구조와 항목은 팬 CYOA 「Type Moon / Becoming Magus」(Made by Selina)를 바탕으로 했어요.
